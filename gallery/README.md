# Galeria do RV-10

Coloque nesta pasta as screenshots que você quiser publicar no site.

Formatos aceitos pelo site: JPG, JPEG, PNG, WebP, AVIF e GIF.

Recomendação para screenshots do Flight Simulator:
- versão publicada: WebP, largura máxima aproximada de 1920 px, qualidade 78–82;
- miniaturas não precisam ser criadas manualmente: a página usa a própria imagem e a apresenta em tamanho reduzido;
- mantenha os arquivos com nomes simples, por exemplo `etapa-01.webp`, `pouso-miami.webp`.

Depois de fazer o commit/push para o GitHub, a página consulta a pasta pública `/gallery` e atualiza a prévia e a galeria.
